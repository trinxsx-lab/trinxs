Política de Privacidade

Esta página descreve, de forma simples, os dados coletados pelo formulário de contato do site trinxs.com.br.

Responsável pelo tratamento

TRINXS Inteligência Operacional, contato pelo e-mail contato@trinxs.com.br.

Dados coletados

O formulário coleta nome, e-mail corporativo, empresa (opcional), quantidade de unidades e quantidade de contratos de telecom ativos, informados voluntariamente por quem deseja um retorno de contato.

Finalidade

Os dados são usados exclusivamente para responder ao contato e apresentar o diagnóstico e os serviços da TRINXS Inteligência Operacional.

Como os dados são enviados

Atualmente o formulário não envia dados para um servidor do site: ao enviar, o programa de e-mail do visitante é aberto com os dados preenchidos, endereçado a contato@trinxs.com.br. Não há armazenamento de dados do formulário em servidor próprio do site.

Compartilhamento e retenção

Os dados não são compartilhados com terceiros para outras finalidades. Os e-mails recebidos são mantidos apenas pelo tempo necessário para responder e acompanhar o contato, sendo excluídos quando não houver mais necessidade. Para solicitar acesso, correção ou exclusão dos seus dados, escreva para contato@trinxs.com.br.

Contato

Para dúvidas sobre esta política: contato@trinxs.com.br.

Última atualização: novembro de 2026. Esta página será revisada caso o formulário passe a enviar dados para um servidor ou ferramenta externa.
